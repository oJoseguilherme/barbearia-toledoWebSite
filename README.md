# Barbearia Toledo - Website Oficial

Website estático responsivo da Barbearia Toledo (Palmas - TO), incluindo página inicial para escolha de unidade e páginas dedicadas para Matriz e Filial.

## 📍 Estrutura das Páginas

- **`index.html`**: Página inicial com seletor interativo de unidades (Matriz ou Filial).
- **`matriz.html`**: Unidade Matriz (Av. LO-04 / 202 Sul) — Galeria de cortes e barbas, equipe de 10 profissionais, vídeo institucional em destaque, localização com mapa interativo e agendamento via Trinks e WhatsApp.
- **`filial.html`**: Unidade Filial (Palmas Brasil Sul) — Apresentação da unidade, equipe local (Elias e João), vídeo institucional em destaque, mapa interativo e agendamento direto.
- **`imagens/`**: Identidade visual completa, fotos dos profissionais, fotos dos serviços, vídeos institucionais otimizados para web e fontes tipográficas locais.

## 🚀 Tecnologias

- HTML5 semântico
- CSS3 moderno e responsivo (sem dependências externas de compilação)
- JavaScript nativo para carrossel de fotos/equipe, menu mobile e controles de vídeo
- Tipografia auto-hospedada para máxima performance
